### О программе

Программа сбора данных о самолетах в воздушных пространствах тех стран, которые вы выберете.

В программе используются следующие модули

### Пакет src

### Модуль APIAdapter.py:
В модуле реализован class APIAdapter, включающий в себя методы:

#### get_coordinates 
 - для сбора географических координат стран используется API nominatim.openstreetmap.org

Пример вывода: 
````
["41.6765597", "83.3362128", "-141.0027500", "-52.3237664"]
````

#### get_aeroplanes 
 - для получения информации о самолетах используется API opensky-network.org.

Пример вывода:
````
{
    "time": 1766142246,                 // UNIX-время сервера OpenSky (секунды)
    "states": [
        [
            "4b1812",                   // ICAO24 — уникальный идентификатор борта
            "SWR438A ",                 // Callsign — позывной рейса
            "Switzerland",              // Страна регистрации ВС
            1766166618,                 // time_position — время последнего обновления позиции
            1766166618,                 // last_contact — время последнего контакта
            -0.0168,                    // longitude — долгота (°)
            51.0888,                    // latitude — широта (°)
            4267.2,                     // baro_altitude — барометрическая высота (м)
            false,                      // on_ground — находится ли самолёт на земле
            189.7,                      // velocity — горизонтальная скорость (м/с)
            129.39,                     // true_track — курс (градусы)
            14.63,                      // vertical_rate — вертикальная скорость (м/с)
            null,                       // sensors — ID сенсоров (null = неизвестно)
            4282.44,                    // geo_altitude — геометрическая высота (м)
            "2061",                     // squawk — код ответчика (транспондера)
            false,                      // spi — специальный сигнал (emergency/priority)
            0                           // position_source — источник позиции
        ],
        ...
    ]
}
````

Для класса APIAdapter создан абстрактный класс AbstractAdapter в модуле AbstractAdapter.py, 
который является родительским классом.

### Модуль Planes.py:
В модуле реализован class Planes, включающий в себя методы валидации объектов самолета и методы 
сравнения объектов самолета между собой.


### Модуль WorkerFile.py
В модуле реализован class WorkerFile, включающий в себя методы:

#### add_info_plane_in_file:
 - Метод добавления информации о самолете в файл с выбранными параметрами. Файл для хранения 
данных InfoPlane.json.

Пример данных файла:
````
[
    {
        "Время": "2026-02-15 16:08:37+03:00",
        "Страна": "Malta",
        "Позывной": "WZZ63WQ ",
        "Скорость": "234.19 м/с.",
        "высота": "10690.86 м.",
        "Статус": "В полете"
    }
]
````
#### read_info_plane_from_file
 - Метод чтения данных из файла.

#### delete_info_plane_from_file
 - Метод удаления файлов из файла (очищает файл).

Для класса WorkerFile создан абстрактный класс AbstractWorkerFile в модуле AbstractWorkerFile.py, 
который является родительским классом.


### Пакет utils

### Модуль country_name.py:
#### get_country_name
 - Функция получения названия страны на английском языке, чтение данных из файла Countries.json, 
содержащий названия стран на русском и английском языках. Возвращает None если страна не найдена.
Если выбранная страна не перевелась на английский можно добавить данную страну в файл Countries.json.

Пример вывода:
````
Россия -> Russia
````

### Модуль object_list.py:
#### get_object_in_list
 - Функция преобразования данных о самолетах в объекты самолётов класса Planes в воздушном 
пространстве страны. Использует словарь, полученный в методе get_aeroplanes из класса APIAdapter, 
содержащий информацию о каждом самолете в воздушном пространстве страны.
    
Пример вывода:
````
Austria AOJ72T   204.89 10660.38 False
Hungary WZZ3174  202.41 6324.6 False
Hungary WMT401   204.62 11094.72 False
Hungary WZZ115Z  245.77 10325.1 False
Hungary FCA1UA   87.07 754.38 False
````

### Модуль main.py
#### Функция main:
 - отвечает за основную логику проекта с пользователем и связывает функциональности между собой.
 - Функция main предоставляет пользовательский интерфейс с возможностью выбора страны, вывода ТОР 
самолетов по высоте и по скорости.
